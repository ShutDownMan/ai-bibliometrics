# Final manuscript source

Compile from this directory with an installed pdfLaTeX distribution:

    pdflatex -interaction=nonstopmode -halt-on-error main.tex
    pdflatex -interaction=nonstopmode -halt-on-error main.tex

The final manuscript is seven pages. References are embedded in main.tex;
BibTeX is not needed. The event-supplied IEEEtran class and page artwork,
three vector figures, and generated validation inputs are included.

The public supplement is available file by file in the repository's
supplement/ directory. Older submission ZIPs are historical.
