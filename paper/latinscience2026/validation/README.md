# Human-validation package

## Current files

- Sampling frame: `runs/latin_science_2026/indicators/validation_sample_130.csv`
- Rater workbook: `runs/latin_science_2026/indicators/validation_ratings_130.xlsx`
- Pilot ratings: `runs/latin_science_2026/indicators/pilot_ratings_*.json`

## Before distributing the workbook

1. Save a protected crosswalk from Excel `Form ID` to corpus `id`.
2. Give each rater a separately named copy of the same blinded workbook.
3. Do not give raters automatic scores, source, year, authors, journal or prior
   ratings.
4. Collect the two completed files without modifying the original blank form.

The 14 double-rated pilot papers help refine the rubric only. They are not part
of the confirmatory validation result.
